# Li3InCl6-XANES-Study
This repository contains the density functional theory (DFT) calculated XANES data of pristine Li3InCl6 solid electrolyte, Schottky defect and Li and Cl Frenkel defect containing structures and Li|Li3InCl6 reactive interface considered as part of our work titled "Analysing local structure and reactive interface of Li3InCl6 solid electrolyte and Li metal anode: Insights from ab initio XAS simulations". 
In case you use any of the data here, we would appreciate a citation
